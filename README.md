### From application to deployment

I'm a full-stack developer in fintech. I build Angular interfaces, Node.js and Python/FastAPI backends, and event-driven services on Kafka and PostgreSQL, and I deploy them with Docker and Nginx on cloud VMs. Lately most of my time goes into applied AI: in-app assistants that read live application data and help users get work done, not just answer questions.
